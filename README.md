# ThinkFirst-Gemma 

A reasoning-first AI model fine-tuned using Google Gemma and Tunix,
designed to explicitly show step-by-step reasoning before generating answers.

## 🔗 Kaggle Notebook
https://www.kaggle.com/code/krishgarg9395/thinkfirst-gemma

##  Features
- Reasoning-first response format
- Tunix-based fine-tuning
- TPU-enabled training on Kaggle
- Transparent model outputs for verification

##  Use Cases
- Education & learning
- AI transparency & trust
- Judge verification pipelines

## Hackathon Submission
This project was built as part of a Google Tunix Hackathon submission.
